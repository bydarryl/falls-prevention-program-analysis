# falls-prevention-program-analysis
## Description 
Cleaning and stratified analysis of a synthetic falls-prevention dataset (Excel + R)

## Goal
Practice cleaning messy data and checking whether a falls-prevention program benefits participants overall or only some subgroups.

## Data
- Synthetic (AI-generated), 200 rows, one row per participant
- Columns and valid values: see [docs/data_dictionary.md](docs/data_dictionary.md)
